# 神韵 21×21 与 21×26 非法音节对的意图识别对比

> 状态：现行实现的结构辨析与后续设计依据，不改变当前方案行为。
>
> 日期：2026-11-01。
>
> 相关记录：[神韵 21×26 飞码四码顶空桶路由讨论](2026-11-01-shenyun-21x26-feima-vacancy-routing.md)。

## 术语校正

本文讨论的重点不是“某个码位最终有没有候选”，而是：输入中的第 1～2 码或第 3～4 码不能构成合法完整音节时，这条否定信息能够排除哪些编码解释，从而帮助判断用户正在输入单字、二字词、三字词还是四字词。

因此更准确的说法是“非法音节对提供的意图判别信息”，而不是“空候选桶”。一个非法音节码仍可能被二简、固定词、声声二字词或其他路径占用；反过来，一个合法音节码也可能因为实际词库没有对应词而没有某类候选。

本文记：

- `A` 为 21 个声键；
- `B` 为 5 个与 21 个声键互斥的辅键；
- `V(xy)` 表示二键 `xy` 按当前系统词典与规范拼写可以形成完整单字音节；
- `¬V(xy)` 表示不能形成上述完整音节；
- 运行时合法性只看系统词典，不受用户词频影响，并忽略整组词频不超过 1 的大字集兜底音节。

## 两个键域的根本差异

21×21 的冰雪弎拼、冰雪健道使用：

```text
U = A
A ∩ B = ∅
```

声韵码只能是 `AA`。一旦出现 `B`，程序便知道它不是韵键，而是辅助码或独立 630 域的一部分，因此音节域内部没有“空 `AB`”这种类型。

21×26 的两套神韵方案使用：

```text
U = A ∪ B
A ∩ B = ∅
```

声韵码 `AU` 既可能落在 `AA`，也可能落在 `AB`。当 `AU` 非法时，还必须观察第二键属于 `A` 还是 `B`；两者能够排除的词长路径不同。这正是 21×26 比 21×21 多出的特殊意图信息。

## 21×21：第 1～2 码提供的信息

21×21 的单字完整音码是 `A₁A₂`：

| 第 1～2 码 | 可以排除或保留的解释 |
| --- | --- |
| `V(A₁A₂)` | 单字完整音节仍成立；该二键也可能因为固定候选或联合查询出现词语，不能仅凭两键判定词长 |
| `¬V(A₁A₂)` | 可以排除普通单字完整音节；两键可解释为两个字的声母，并且仍可能继续形成 `AAA` 三字词或 `AAAA` 四字词 |

非法 `AA` 的价值是排除“这是一个完整单字音节”，而不是直接唯一确定“这是二字词”。如果下一键是 `B`，可进一步支持声声二字词的辅助筛选；如果下一键是 `A`，则继续进入三字或四字声母路径。

现行两套方案都只允许运行时非法 `AA` 接受一次声声二字词辅助码，第二个辅助码会被 `shape_processor` 阻止。冰雪健道的 `initial_pair` 翻译器还会在查询声声二字词前显式检查 `¬V(AA)`；冰雪弎拼由 `t12` 联合查询音节与代理码，但为声声二字词接受辅助键时同样受运行时非法音码约束。

需要另外区分：冻结扩展音节域有 75 个未被音节占用的 `AA`，但它们已经安排了二简；当前系统词典按运行时口径得到 80 个非法 `AA`。这些码位可以有可见候选，却仍然在“能否形成完整单字音节”的判定中属于非法音节对。

## 21×21：第 3～4 码与四码联合池

21×21 的四码 `A₁A₂A₃A₄` 同时承载：

```text
二字词：A₁A₂ | A₃A₄
四字词：A₁ | A₂ | A₃ | A₄
```

两对音节的合法性给出以下意图信息：

| `V(A₁A₂)` | `V(A₃A₄)` | 二字词解释 | 四字词解释 |
| --- | --- | --- | --- |
| 是 | 是 | 保留 | 保留 |
| 否 | 是 | 排除 | 保留 |
| 是 | 否 | 排除 | 保留 |
| 否 | 否 | 排除 | 保留 |

因此只要前一对或后一对不能构成合法音节，就可以排除标准二字词全码，四字词声母码仍然成立。这里不需要建立专门的 vacancy 路由：二字词查询自然得不到完整结果，四字简拼查询继续产生候选；两种解释都成立时，当前翻译器和过滤器将它们留在联合候选池中排序。

按当前运行时 361 个合法 `AA`、80 个非法 `AA` 计算，全部 `21⁴ = 194481` 个四码形态中：

| 类型 | 数量 |
| --- | ---: |
| 前后两对都合法，二字词与四字词解释均可能 | `361² = 130321` |
| 仅前一对非法 | `80×361 = 28880` |
| 仅后一对非法 | `361×80 = 28880` |
| 前后两对都非法 | `80² = 6400` |
| 至少一对非法、因而可排除标准二字词 | `64160` |

这些数字只描述音节结构是否允许二字词，不保证实际词典一定存在二字词或四字词候选。

## 21×21：三字词没有音节对分流

21×21 三字词的基础形态是 `A₁A₂A₃[B...]`。三个 `A` 都直接表示三个字的声母，不要求任意相邻两键先组成完整音节，因此：

- `AAA` 不需要检查 `V(A₁A₂)` 或 `V(A₂A₃)`；
- 不存在由“第三音节音码非法”触发的三字词替代路线；
- 全部 `21³ = 9261` 个 `AAA` 形态在编码结构上都属于三字及以上简拼域；
- 某个 `AAA` 没有候选只表示当前词库没有相应词，不是音节合法性造成的特殊分流。

大写韵键可以为前三个音节补韵，但那是显式增加信息，不是利用非法音节对判断词长。

## 21×21 的 `AB/ABB` 是独立 630，不是非法音节对

由于 `B` 不属于 21 键声韵域，`AB/ABB` 从语法上就是独立的固定候选空间：

```text
AB：21×5 = 105
ABB：21×5×5 = 525
合计：630
```

冰雪弎拼当前使用 105 个二码位和 506 个三码位，冰雪健道使用 105＋525。冰雪弎拼剩余的少量未填三码位只是固定词表没有选择候选，不是由 `¬V(AA)` 推导出的意图信息。

## 21×26：第 1～2 码必须区分空 `AA` 与空 `AB`

21×26 当前有 403 个运行时合法 `AU` 和 143 个非法 `AU`；非法部分进一步分成 134 个 `AA` 与 9 个 `AB`：

| 第 1～2 码 | 意图信息 |
| --- | --- |
| 合法 `AU` | 单字或二字词第一音节仍成立 |
| 非法 `AA` | 排除单字完整音节，但两键仍可解释为两个声母，可走声声二字词或继续 `AAA/AAAA` |
| 非法 `AB` | 既不是完整音节，第二键又不能作为下一字声母；普通单字、声声二字词和三／四字声母前缀都被排除，当前自然形成保留域 |

这 9 个非法 `AB` 及其 `AUB/AUBB` 后代是 21×26 独有的保留空间；21×21 因为音节域里不存在 `AB`，没有对应结构。

## 21×26：第 3～4 码直接参与三、四字词判长

在前三键都是 `AAA` 的前提下，第 3～4 码给出：

| 第 3～4 码 | 三字词解释 | 四字词解释 |
| --- | --- | --- |
| 合法 `AU` | 标准 `AAAU` | 仅当第 4 键属于 `A` 时同时保留 `AAAA` |
| 非法 `AA` | 排除标准 `AAAU` | 第 4 键仍是声键，保留 `AAAA` |
| 非法 `AB` | 第 4 键改作第一辅码，走 `AAA+B` | 第 4 键不是声键，排除 `AAAA` |

因此 21×26 的非法后半音节对不仅排除路径，还会主动选择另一条三字词路线；21×21 没有对应机制。

在 `AAAA` 子域内，当前 441 个 `AA` 中有 307 个运行时合法音码、134 个非法音码。其意图组合为：

| 前一对 | 后一对 | 仍可能的标准词长解释 | 数量 |
| --- | --- | --- | ---: |
| 合法 `AA` | 合法 `AA` | 二字＋三字＋四字 | `307² = 94249` |
| 非法 `AA` | 合法 `AA` | 三字＋四字 | `134×307 = 41138` |
| 任意 `AA` | 非法 `AA` | 仅四字 | `441×134 = 59094` |

这里后一对是否合法比前一对携带更多词长信息：后一对非法会同时排除标准二字词和标准三字词，只留下四字词；仅前一对非法仍允许第三字使用合法的 `A₃A₄` 音码，所以三字词与四字词都可能成立。

在 `AAAB` 子域内，当前有 96 个合法 `AB` 音码和 9 个非法 `AB` 音码：合法者走标准三字词 `AAAU`，非法者走 `AAA+B`。按前两声键的 441 种组合计算，非法 `AB` 提供 `441×9 = 3969` 个三字词第一辅码形态。

## 当前实现为何不同

21×21 的意图识别主要依赖编码族天然互斥：`B` 不可能是韵键，`AAA` 明确是三字及以上简拼，`AAAA` 的二字词和四字词解释可以由各自翻译器自然产生或消失。冰雪健道的 `enforce.lua` 在四码时同时接受双拼和简拼，冰雪弎拼由 `t12` 与 `jianpin` 两路查询共同形成候选池。

21×26 必须显式查询音节合法性。`shenyun.lua` 分别计算 `first_vacant` 和 `third_vacant`，再建立 `AA`、`AUAU`、`AAAU`、`AAA+B`、`AAAA` 等路线，并按候选质量合流。没有这些显式路线，程序无法仅凭键类区分空 `AA` 与空 `AB` 的不同意图。

## 对比结论

| 结论 | 21×21 | 21×26 |
| --- | --- | --- |
| 非法前半音节对 | 只有非法 `AA`，排除单字音节但仍可解释为多字声母 | 非法 `AA` 同左；另有非法 `AB`，可排除普通多字声母路径并形成保留域 |
| 非法后半音节对 | 在 `AAAA` 中只负责排除标准二字词，四字词自然保留 | 非法 `AA` 指向四字；非法 `AB` 指向 `AAA+B` 三字词 |
| 三字词 | `AAA` 不依赖音节合法性，没有 vacancy 分流 | `AAAU` 依赖第三音节合法性，存在标准与 `AAA+B` 两路 |
| 四码候选池 | 二字词与四字词联合 | 二字词、三字词、四字词联合 |
| 独立 `AB/ABB` | 是 630，键类天然无歧义 | `AB` 属于声韵域，不能建立同样的独立 630 |
| 是否需要显式 vacancy 路由 | 短码辅助筛选需要；四码二／四字分流通常不需要 | 需要显式区分前后空 `AA/AB` |

最终判断是：21×21 的非法音节对确实提供意图信息，但信息形态较单一。它主要在前两键排除单字、在四码中排除二字词；三字词不依赖音节对合法性。21×26 因为把五个 `B` 键也纳入韵键域，非法 `AB` 额外产生保留域与 `AAA+B` 三字词回收路线，所以需要更细的识别和回归保护。
