# 神韵 21×28 两极之间的盆地搜索

> 状态：探索性研究，尚未替换「冰雪神韵·形 / ·调」原型或发布方案。
>
> 本文接续[《R10 演化 21×28 与 180 空桶极端方案的碰撞对比》](shenyun-r10-vs-180-vacancy-collision.md)：上一阶段确认 R10 演化端性能好、旧 180 空桶端碰撞好；本阶段从两端相向搜索，判断中间是否存在新的 Pareto 盆地。
>
> 可复算的精选映射、性能代理与逐档真实碰撞数据见 [`data/shenyun-21x28-hybrid-frontier.json`](data/shenyun-21x28-hybrid-frontier.json)。

## 结论

**有新的盆地，而且不是一个孤立点。** 当前至少形成性能偏置和碰撞偏置两条前沿：

- **性能侧主点 D4/M39/V0**：`S2=67.605 ms`，五档跨族碰撞均值 `3.909%`，首选损失均值 `1.329%`。它与上一轮 D3 的性能几乎相同，却把碰撞均值降低 `15.74%`。
- **折中主点 D5/M41/V1-FAST**：`S2=67.949 ms`，碰撞均值 `3.840%`，首选损失均值 `1.244%`，Top 10k 最大桶为 17。相对上一轮 D3，碰撞均值降低 `17.23%`，S2 只增加 `0.53%`。
- **碰撞侧主点 D5/M41/V1-COLL**：`S2=69.537 ms`，碰撞均值 `3.752%`，是本轮非极端方案最低值。它比旧 180 空桶极端案快 `13.90%`，但碰撞仍比旧案高 `75.03%`。

所以，性能与碰撞之间不是从 `67.6 / 4.64%` 直接跳到 `80.8 / 2.14%`；中间至少存在一段可用前沿：

```text
性能端                    新盆地                         碰撞端
67.61 ms / 3.91%  ->  67.95 ms / 3.84%  ->  69.54 ms / 3.75%  ->  80.77 ms / 2.14%
D4 / M39 / V0          D5 / M41 / V1 FAST        D5 / M41 / V1 COLL       旧 180 空桶
```

旧 180 空桶案仍是纯碰撞冠军，但已经不再是取得明显碰撞改善的唯一办法。

## 搜索方法

硬约束沿用上一阶段：

- Common399 `399/399` 无重；
- 整韵映射；
- `,.` 只作 U，不作声键 A；
- 固定辅键/声调顺序 `IEUAO`；
- V 不设上限。

第一层搜索使用冻结的 R11 性能因子和两个空桶代理：

1. 21×21 A×A 区域中的空桶数；
2. Top 500/1k/2k/5k/10k 三四字词高频 AA 前缀落入空桶的加权比例。

搜索从上一轮 D3、D4、D5 以及旧 180 空桶方案同时出发，再围绕真实回放优胜点做局部加密。累计约 285 万次退火步。空桶代理只负责生成候选，最终排名全部使用真实冰雪词典精算：

```text
二字：AUAU
三字：AAAU
四字：AAAA
```

分别测 Top 500、1k、2k、5k、10k 的跨族受影响词频、跨族首选损失、碰撞桶和最大桶。本轮仍是多起点随机搜索，不是全局最优证明。

## 对空桶代理的新认识

AA 空桶数和热点对准率能帮助搜索跨过性能端与碰撞端之间的谷地，但**不能代替真实碰撞排名**：

- 旧极端案只有 180 个 AA 空桶、热点代理 `0.4850`，真实碰撞却最低；
- D4/M39 有 179 个空桶、热点代理 `0.5456`，真实碰撞为 `3.909%`；
- D5/M41-FAST 有 183 个空桶、热点代理反而较低，为 `0.5360`，但真实碰撞优于 D4/M39；
- 同为 183 个空桶的候选，真实碰撞均值仍可从约 `3.75%` 浮动到 `4.17%`。

原因是“一个 AA 前缀是否为空”只描述了三四字词的一侧。真实 `AUAU / AAAU / AAAA` 碰撞还取决于二字词的完整 AUAU 分布、同桶词频次序，以及三个编码族在第四码上的重合方式。

因此下一轮不应继续单纯增大 AA 空桶权重，而应把真实词表中造成损失的 AA 前缀和第四码冲突对预计算成可快速增量更新的目标。

## 当前建议

在完整 `AUBB / AAA / AAAUBB` 飞码状态机尚未复测前，不替换现有方案。若只选择下一轮的三个种子：

- **性能护栏种子：D4/M39/V0**；
- **综合主种子：D5/M41/V1-FAST**；
- **碰撞护栏种子：D5/M41/V1-COLL**。

旧 180 空桶案继续作为碰撞理论侧的对照，不作为综合主案。

## 下一步

1. 将 Top 500～10k 的真实跨族冲突对压缩为可增量计算的局部目标，替换当前空桶热点代理。
2. 围绕三个主种子搜索，优先降低 Top 10k 首选损失和最大桶，同时守住各自的性能护栏。
3. 对最终小集合运行 R11 原始 20 轨道精算，并补做 `AUBB / AAA / AAAUBB` 完整飞码状态机回放。
4. 只有状态机与 Rime 候选行为稳定后，才考虑更新「冰雪神韵·形 / ·调」配置；本阶段不写 README 或 release。
