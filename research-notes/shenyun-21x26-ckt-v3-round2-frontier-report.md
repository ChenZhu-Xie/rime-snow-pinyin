  - 容量口径：`capacity = [21, 26]`（21 键声母、26 键韵母，零声韵飞键：声母严格不使用 `A/E/I/O/U` 五个元音键）；
  - 辅码锁定：`tone = 'IEUAO'`（即 `AEUIO` 五元音键作为形码/声调辅码，且槽位映射顺序固定）；
  - 无重码约束：`Common399` 音节 `399/399` 100% 裸二键唯一（`unique = 399`）；
  - 零声母规范：`pure-y`（所有 `i/u/v` 零声母及标准 `Y` 组零声母统一归入 `Y` 键，`A/E/O` 三组零声母合并为单一槽位 `AEO`）；

- **双引擎独立核验**：所有入选方案均通过 Numba 精确评估器与 `node score_candidates_v3.js` 独立交叉核对，最大绝对误差 `max |Numba - JS| = 9.770e-14`。

## 2. 第 2 轮底层数学与算法突破

### 2.1 精确记忆量代数与「免费声母重排预算」（`W -> W` & `v -> V` 法则）

根据 `opt.memory(st)` 的精确定义，在 `pure-y`（$\mathbb{I}(Y \ne \text{'Y'}) = 0$）且 `A=E=O`（$|\text{set}(A,E,O)| = 1$）口径下，方案总记忆量 $M$ 满足恒等式：

$$M = 32 + D + V + |\text{set}(A,E,O)| + \mathbb{I}(W \ne \text{'W'}) + \mathbb{I}(v \ne \text{'V'}) = 33 + D + V + \mathbb{I}(W \ne \text{'W'}) + \mathbb{I}(v \ne \text{'V'})$$

第 1 轮绝大多数种子将 `(q, W)` 移至 `Q/D/S`（触发 $\mathbb{I}(W \ne \text{'W'}) = 1$）且未约束 `v` 韵母原位（触发 $\mathbb{I}(v \ne \text{'V'}) = 1$），导致 $M = 35 + D + V$。  
第 2 轮通过利用以下两条代数省记忆法则：
1. **法则一（`W -> W` 原位配对）**：令 `(q, W) -> W` 或 `(x, W) -> W`，消除 $\mathbb{I}(W \ne \text{'W'}) = 1$ 的额外记忆代价；
2. **法则二（`v -> V` 韵母原位锚定）**：由于 `v` 仅与 `j/q/x/n/l/Y` 拼合，在韵母优化中将 `v` 锚定在 `V` 键（$\mathbb{I}(v \ne \text{'V'}) = 0$），且对 `CKT v3` 速度影响极小（$< 0.003$）。

**核心收益**：两条法则叠加后，$M = 33 + D + V$，在**完全相同的记忆量 $M$ 下白白多解锁 $+1 \sim +2$ 个声母重排预算 $D$**（例如在 `M42` 下可容纳 `D=9`、在 `M40` 下容纳 `D=7`、在 `M39` 下容纳 `D=6`、在 `M36` 下容纳 `D=3`），直接改写了 `M35..M44` 全段帕累托前沿。

### 2.2 舌面音三元组全排列 $\text{Perm}(\{f, W, \text{AEO}\}) \leftrightarrow \{j, q, x\}$ 与 42,778 声母拓扑枚举

由于 `j/q/x` 仅接齐齿呼/撮口呼韵母，而 `{f, W, AEO}` 仅接开口呼/合口呼韵母，任意双射配对 $\pi: \{f, W, \text{AEO}\} \to \{j, q, x\}$ 均与任意合法韵母表 100% 正交相容（`unique = 399`）。  
第 2 轮编写 [`generate_and_screen_r2_initials.py`](../scripts/research/generate_and_screen_r2_initials.py) 穷举了 $D = 1..10$ 下全部 **42,778** 个合法 21 键 `pure-y` 声母拓扑，筛选出 **410** 个分桶精英拓扑（[`r2_elite_initial_topologies.json`](./data/r2_elite_initial_topologies.json)），发现了三个全新的高价值声母盆地：

- **`JKW` 盆地**：`(j, AEO) -> J, (q, W) -> W, (x, f) -> K`（配合 `k -> X/Q/S`），在省下 $\mathbb{I}(W \ne \text{'W'}) = 0$ 的同时把主行食指 `F` 键腾给最高频翘舌音 `zh`。
- **`JW_JWX` 极简三元盆地**：`(j, f) -> J, (q, W) -> W, (x, AEO) -> X`，仅需 `D=2`（`M36`）即可同时达成 `zh -> F, ch -> V, sh -> Q, W -> W`。
- **`WJ_JWK` 超高主行浓缩盆地**：`(j, f) -> J, (q, AEO) -> W, (x, W) -> K`，将高负载声母最大程度汇聚在主行键位，使主行占比突破 **`56.12%`**。

### 2.3 预计算一元张量 + CSR 稀疏二元差分 + 3-Final 循环轮换退火

在 [`explore_21x26_round2.py`](../scripts/research/explore_21x26_round2.py) 中，针对每个候选声母拓扑预计算一元耗时表 `U_kc1[35,26]`、`U_sc1[35,26]`、`U_w2[2,35,26]`，结合 CSR 关联边精确增量更新与 **3 韵母循环轮换（3-way cycle）**，在 5 条专项赛道上完成了深度盆地与沟壑挖掘，共收获 **789** 个第 2 轮高质量新候选（[`r2_discovered_candidates.json`](./data/r2_discovered_candidates.json)）。
