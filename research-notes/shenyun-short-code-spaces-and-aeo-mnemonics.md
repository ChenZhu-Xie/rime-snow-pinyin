# 神韵 21×26 AUBB 编码空间校正

## 结论

本报告只校正最近的 **21×26 `AUBB` 方案**研究。当前只保留四码层的跨族分流指标：

```text
二字：AUAU
三字：AAAU
四字：AAAA
```

`AA`、630、五六码续码都不应再作为独立跨族碰撞维度加入本轮布局评价。

这里不评价 21×21 方案。仓库 README 所链接的早期 21×21 研究采用另一套路径，其相应碰撞空间是 `AA / AAA / AAAA`，不是本轮 21×26 使用的 `AUAU / AAAU / AAAA`。两者必须分开叙述和测量。

## `aa / ee / oo` 不适用于当前键域

此前的诊断变体把 ØA、ØE、ØO 分别强制放到同名的 `A/E/O` 实体键，同时令 `a/e/o` 韵也落在同名键。这不是把它们安排到现有声键中的 `ss/rr/ll` 一类做法，而是直接使用了 `IEUAO` 辅码键作为新增声键。

结果是：

- 原 21 个声键扩大为 22～24 个；
- 声键集合与 `IEUAO` 辅码键集合相交；
- 比较口径实际向 26×26 靠拢，不再是合法的 21×21 或 21×26。

如果改为把 ØA、ØE、ØO 安排到 `AEUIO` 之外的现有声键，它们就只是普通的零声母分组。每增加一个需要单独记忆的映射，仍应按既有 M 口径核算；不能因为 26×26 方案使用 `aa/ee/oo`，就在较小键域中无条件免计。

外部方案的规则本身没有问题，只是键域前提不同：

- Rime 小鹤双拼用首字母重复规则生成 `aa/oo/ee`。[Rime 小鹤双拼 schema](https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_flypy.schema.yaml)
- 万象带调双拼把 `aa/oo/ee` 定义为单韵母 `a/o/e` 的轻声特殊编码。[万象带调双拼设计](https://amzxyz.github.io/rime-wanxiang/doc/wxsp.html#_2)

这些属于 26×26 口径的便利，不能直接移植为 21×21 或当前 21×26 声域的免费特例。此前 56 个变体的数值只说明这种越界构造对性能影响不大，不构成采用理由。本方向停止，不再进入正式搜索或 HTML。

## `AA` 空槽不是碰撞

在当前 21×26 `AUBB` 方案中，`AA` 内没有被单字 `AU` 使用的位置会由二简词填满。每个位置最终仍只安排一个固顶对象，因此：

- `AU` 落入 `AA` 的位置用于二码单字；
- 其余 `AA` 空槽用于二简词；
- 空槽多少影响可安排多少二简，但不构成候选碰撞；
- 既然设计会把空槽补满，本轮无需把 `AA vacancy count/value` 加入碰撞指标。

它是当前 21×26 方案的固定码位分配问题，不是需要与四码碰撞率合并的跨族桶问题。

## AUBB 方案不引入 630 干扰

此前报告把 `AB` 单字与二键 630、`AUB` 与 `ABB` 列为潜在干扰，这是把本轮范围之外的 21×21 `AABB` 路线问题误套到了当前 21×26 `AUBB` 路线。

对这里研究的 21×26 `AUBB` 方案：

1. 不设置独立的 630 编码层，因此不存在“`AB` 单字与二键 630 抢码”的评价对象；
2. `AB` 本来就是 `AU` 中 `U` 落在 B 键的子集；
3. `ABB` 相应属于 `AUB` 的继续细化，而不是另一编码家族；
4. 因而也不存在需要单列的 `AUB ↔ ABB` 跨族碰撞。

固顶候选如何选、单字如何继续加 B 辅码，属于同一路径内部的候选排序与细化，不应误记为布局族之间的碰撞。

## 五、六码不新增跨族竞争

可能写出的后续形态包括：

```text
五键：AUAUB / AAAUB / AAAAB
六码：AUAUBB / AAAUBB / AAAABB
```

但这些续码都建立在各自已经到达的四码状态上：

```text
AUAU → AUAUB → AUAUBB
AAAU → AAAUB → AAAUBB
AAAA → AAAAB → AAAABB
```

只要 `AUAU / AAAU / AAAA` 在第四键已经分流，后续输入 B 不会让两个不同的四码前缀重新合并成相同状态。因此五、六码无需另做跨族碰撞指标。它们只可能继续拆分各自四码桶内的候选。

## 当前唯一需要优化的跨族层

本阶段只为 21×26 `AUBB` 方案保留现有四码测评：

| 家族 | 四码形态 | 评价内容 |
|---|---|---|
| 二字词 | `AUAU` | 与三、四字词是否进入同一四码桶 |
| 三字词 | `AAAU` | 与二、四字词是否进入同一四码桶 |
| 四字词 | `AAAA` | 与二、三字词是否进入同一四码桶 |

仍按 Top 500/1k/2k/5k/10k 五档报告：

- 跨族受影响词频；
- 跨族首选损失；
- 跨族碰撞桶；
- 全部碰撞桶；
- 最大桶。

四码碰撞占当前跨族问题的大头，也是后续搜索的唯一碰撞目标。AA 二简填充、B 辅码续分和候选固顶分别在实现阶段处理，不再扩张布局搜索指标。
