# 21×21：放宽 M、D 后的八条 B 路径联合搜索

延续[正式 B 集合基准和 D=0 搜索](shenyun-21x21-b-sets-benchmark.md)：锁定实体辅助键 **AVUIO** 及引擎中的 **IVUAO** 顺序，21×21 格局，四条单字加权非首选率各自严格小于 S005。再联合改善四条二字词路径、R11 `S2` 上界和 v5 系综；词路径额外严格小于 S005 的布局另行筛出。B 指辅助集合而不是一笔／两笔：单字键道为形码首、次键；三拼为声调、纯笔画首键。二字词 B1/B2 按次字、首字的形码或声调输入。三拼单字第二 B 按运行时映射允许的**所有首笔编码**判断首选。

[平均键数计算](../scripts/research/analyze_shenyun_21x21_b_path_lengths.py)计入裸声韵码与追加至第二 B 的首选停步，**不计仍非首选时的选重、上屏等行为**。M48/D7 双胜 R9 的键道单字 / 三拼单字 / 键道二字词 / 三拼二字词分别为 **2.170984 / 2.175334 / 4.241674 / 4.248941**，S005 分别为 **2.177456 / 2.180760 / 4.244144 / 4.251513**；[全部代表数值](data/shenyun-21x21-b-paths-wide-mean-lengths.json)可以核对。裸二键加权音节非首选率为 **0.4911%**，也低于 S005 的 **0.9292%**。M47/D6 双胜布局的相应四项键数为 **2.174820 / 2.179116 / 4.241940 / 4.249182**，裸二键音节非首选率 **0.5563%**，同样低于 S005。

这里的“优于”是固定字词频、排序与冻结 R11 上界模型的结果。真实 Rime 候选顺序、词频更新、实际输入习惯和 v6 表现另需验证；特别是部分 M42–M47 布局的词二 B 领先不足 0.002 个百分点，不宜将严格过线视作有充足抗扰动余量。
