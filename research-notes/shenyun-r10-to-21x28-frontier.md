# 从 R10 21×26 向神韵 21×28 渐进扩展

> 状态：探索性研究，尚未替换「冰雪神韵·形 / ·调」原型或发布方案。
>
> 本文接续[《神韵 21×28 六种标点韵排列：真实词表阶段测量》](shenyun-21x28-six-layout-benchmark.md)和[《冰雪神韵·形 / ·调：原型方案与 R11 全量测评》](shenyun-21x28-schemas-and-r11-benchmark.md)。上一阶段从空桶结构出发；本阶段改为把 `R10-21X26-M39-08` 原样嵌入 21×28，再在性能护栏内逐步开放 `,.`。
>
> 可复算的精选映射和逐档数据见 [`data/shenyun-r10-21x28-frontier.json`](data/shenyun-r10-21x28-frontier.json)。

## 结论

这条路线成立，而且明显优于此前“先固定 D1/V0/180 个 A×A 空桶，再优化碰撞”的路线。

1. **21×26 嵌入 21×28 时，`R10-21X26-M39-08` 的全部指标逐值不变。** 多出的 `,.` 可以先完全不用，因此 21×28 的性能下限不应低于 R10；旧神韵 `80.767 ms` 的问题来自搜索约束与目标，不来自 28 韵键本身。
2. **D4/M38/V0 已找到严格优于 R10 的 28 键点。** S2、v4、v5、v6 和日常 MX 五项均改善，五档四码跨族碰撞平均下降 `9.47%`，M 还由 39 降到 38。
3. **D5/M39/V0 已找到两个更强的 28 键点。** 均衡点五项性能全部改善，跨族碰撞平均下降 `14.95%`；性能点的 S2 降低 `2.17%`、v5 降低 `0.93%`，碰撞仍下降 `9.42%`。
4. **D3/M38/V0 是当前 28 键碰撞前沿。** 五档跨族受影响率从 R10 的 `5.889%` 降到 `4.639%`，下降 `21.22%`；代价是四项低优性能指标约增加 `0.20%～0.45%`。
5. **D2/M38/V1 仍然可用。** 五档碰撞下降 `15.17%`，各低优性能指标只增加约 `0.36%～0.57%`，日常 MX 提高 `4.35%`。
6. **D1 在放开 V 后可以救回性能，但本轮不值得作为主案。** 最好的性能代表点 S2 已降到 `66.980 ms`，不再是旧方案的 `80.767 ms`；然而 v4/v5/v6 仍落后约 `0.84%～1.30%`，真实四码碰撞反而增加 `9.50%`。D1 可留作极低声母位移对照。

因此，当前推荐继续保留三条 Pareto 支线，而不是过早压成一个方案：

- **综合主案：D4/M38/V0**；比 R10 少一个普通声母位移、少一项 M，同时性能与碰撞均改善。
- **碰撞主案：D3/M38/V0**；用约 `0.45%` 以内的性能代价换约 `21%` 的跨族碰撞改善。
- **性能主案：D5/M39/V0**；保留 R10 的 D/M，全面提高性能并降低碰撞。

## 搜索约束与顺序

硬约束为：

- Common399 `399/399` 无重；
- 整韵、声韵各一键；
- `,.` 只能作为韵键 U，不能作为声键 A；
- 固定辅键/声调顺序 `IEUAO`；
- 先使用 26 个韵键，再开放到 27，最后开放到 28；
- V 不设上限。

搜索从 R10、R11 的 D3/D4 前沿和旧 D1 神韵点分别起步。D2～D5 使用相对 R10 的分层性能护栏；D1 因旧起点远离性能可行域，另以放宽护栏的 100,000 步搜索跨过中间谷地。候选先通过冻结的 R11 因子模型筛选，再由原始 R11 JavaScript 行/路径引擎完整计算 20 条轨道。

碰撞不参与第一层性能退火，而是在候选集上用真实冰雪词典精算：

```text
二字：AUAU
三字：AAAU
四字：AAAA
```

分别测 Top 500、1k、2k、5k、10k 的跨族受影响词频、跨族首选损失、碰撞桶和最大桶。这样可以防止搜索器用空桶代理分数冒充真实词表收益。

本轮是多起点、有界随机搜索，不是全局最优证明。

## `,.` 韵频率的重新判断

上一阶段的 `,=in+ui、.=an` 占全部 S2 击键约 `3.91%`，确实偏重，但“标点韵太常用”不是旧方案落后的唯一原因。本轮候选显示：

| 方案 | `,` | `.` | 两键合计 S2 负载 |
|---|---|---|---:|
| D2 | `en` | `a` | 4.195% |
| D3 | `ei` | `en` | 3.360% |
| D4 | `iao` | `en` | **2.742%** |
| D5 两案 | `ei` | `en` | 3.360% |

D2 即使把高频 `a` 放到句点，综合性能仍只比 R10 低约半个百分点；D4 把低频 `iao` 放到逗号后则实现全面性能改善。这说明标点负载是重要因素，但声母—韵母的整体配对几何、同指和跨行更关键。

例如 D4 的 S2 同指率为 `1.810%`，低于 R10 的 `2.006%`；旧神韵则高达 `12.957%`。D4 的跨行率为 `14.113%`，虽高于 R10 的 `12.372%`，但远低于旧神韵的 `24.075%`。最终性能是这些因素的合成，而不是单看 `,.` 的词频。

## 下一步

1. 以 D4 为主种子、D3 和 D5 均衡点为两侧护栏，做包含真实四码碰撞代理的联合局部搜索。
2. 把 Top 10k 的最坏桶成员和高频首选损失直接加入二阶段目标，尝试降低最大桶，而不只降低平均受影响率。
3. 对三个代表点回放 `AUBB / AAA / AAAUBB` 完整飞码状态机；本报告的碰撞表只精确覆盖 `AUAU / AAAU / AAAA`。
4. 在状态机结果稳定前，不替换现有「冰雪神韵·形 / ·调」配置，也不写入 README 或 release。
