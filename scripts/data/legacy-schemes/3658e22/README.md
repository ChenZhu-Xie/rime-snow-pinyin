# 冰雪键道／冰雪三拼经典基准快照

本目录固定保存提交 `3658e22a151cfaa703a68e3a47a16101efd88e42` 中的冰雪键道与冰雪三拼。下一提交 `b8fd127da9ecb14d07da1ce9a680ca92d91837f0` 首次把两者的双拼部分切换到神韵布局，因此 `3658e22` 是迁移前最后一个完整版本。

这里的原样文件作为 benchmark 输入；根目录中由它们适配得到的 `snow_jiandao_classic`、`snow_sanpin_classic` 进入发布包和默认方案列表。现行 `snow_jiandao`、`snow_sanpin` 分别显示为冰雪健道、冰雪弎拼；经典方案继续使用当时的冰雪键道、冰雪三拼名称，避免把历史合同误写成现行 21×21 合同。

根目录发布适配层并非冻结回放：它只保留本快照的声韵布局，追加辅码分别与冰雪健道、冰雪弎拼共用 CKT v5.1 辅序 `12/231/24`、`12/213/23`，并迁入当前上游的 AA/AAB 空桶、630、字母、数字、生僻字补空、部件拼音、统计和性能修复。逐项结论见[经典方案上游迁移审计](../../../../reports/经典键道三拼上游迁移审计.md)。

快照包含两份主 schema、共用简拼 schema、两份 fixed 表，以及影响固定候选、形辅过滤、代理码、动态首选后置和顶功行为的 Lua 模块。后续 benchmark 应直接读取这些文件和 [`manifest.json`](manifest.json)，不得再把外部冻结回放冒充可复算结果。

`snow_jiandao_chaifen.dict.yaml` 的字形数据从该提交到当前版本仅变更了词典版本头，实际字码未变；`lua/snow/radical_jiandao.txt` 的 Git blob 完全相同，因此不重复保存。旧冰雪三拼依赖的笔画表当时未纳入 Git，复算时统一使用当前受版本控制的 `snow_bihua.dict.yaml`，并在报告中明确这一共享数据口径。
