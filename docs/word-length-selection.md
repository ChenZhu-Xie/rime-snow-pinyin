# 四主码词长直选

冰雪兰道、冰雪兰拼、冰雪键道、冰雪三拼、冰雪莲道，以及冰雪鹤道、冰雪鹤拼、冰雪鹮道支持以下选择键。冰雪四拼、冰雪一拼、冰雪清韵和英拼不接入。

| 按键 | 21×21 方案 | 21×26 方案 |
| --- | --- | --- |
| Shift+逗号，即 `<`／《 | 当前四字词首选 | 当前四字词首选 |
| Shift+句号，即 `>`／》 | 先选五字及以上词首选；没有时选二字词首选 | 先选三字词首选；没有时选五字及以上词首选 |
| 空格 | 当前总首选 | 当前总首选 |

类别优先，类内沿用最终候选顺序，包含固顶、学习、简繁转换和首选后置的结果。查找从整个候选列表开头进行，不以当前页为起点；第一类不存在时才用第二类兜底。直选成功只选择词，不追加书名号。在有效范围内没有目标词长时保留输入；范围外恢复原有标点行为。

## 生效范围

只在中文普通输入段、光标位于输入末尾、当前段恰好四个主码时生效。21×21 的大写补韵不计主码，补辅也不增加主码。例如冰雪兰道的 `rgen` 与补韵后的 `rEgJeFn` 均可按 `<` 选择「人工智能」。冰雪莲道对应为 `rgen` 与 `rSgNeRn`。21×26 的声声空桶和 `AAA+B` 回收路径按实际主码数识别，三声母加一辅仍不触发。输入第五字声母后已经超过四主码，直接用空格选择长词，`<`／`>` 恢复标点行为。

只选择消费当前完整输入的候选，不选仅匹配前半段的短片段或临时整句；原生长词补全仍可参加。选择走正常的 Rime 候选确认路径，保留学习、缓冲和统计。缓冲开启时与普通选词一样确认片段，不强行结束缓冲。

21×26 的 [SBS 声辅声混合入口](sbs.md)从 `SBSU` 四码阶段起同样支持词长直选，后置辅码不改变其范围；`SBSS` 可选新增四字词，`SBSB` 可选新增三字词。它们独立于双拼桶占用情况，三码 `SBS` 阶段仍用普通选词。

## 21×26 的长词

冰雪鹤道、冰雪鹤拼和冰雪鹮道支持四声母的原生长词补全，以及四声母后用大写声母显式续写五字及以上词。首四码必须都是声母；后续大写声母作为新字继续输入，支持七字及更长词。普通小写第五键仍按四码顶功；五辅键继续按单字、二字、三字、四字各自的既有合同筛选。

| 目标 | 冰雪鹤道／冰雪鹤拼 | 冰雪鹮道 |
| --- | --- | --- |
| 「科学发展观」的四声母补全入口 | `kyfs` | `kyfx` |
| 显式续写「科学发展观」 | `kyfsG` | `kyfxG` |
| 显式续写「中华人民共和国」 | `shrmGHG` | `xhrmGHG` |
| 三字词直选示例「计算机」 | `jqji>` | `jsjz>` |
| 无三字路由时的长词兜底示例 | `wyzr>` →「有限责任公司」 | `gfly>` →「股份有限公司」 |

大写续写标记在输入中保留，裸四声母和显式长词使用等长的全大写简拼入口，预编辑仍以小写声母分隔显示。此入口避免与小写双拼完整音节竞争，同时满足 librime 的原生词补全长度条件；`enable_word_completion` 单独启用，音节补全仍关闭。长词后输入小写声母可正常顶屏并开始下一个词；关闭「飞码」时，合法大写续写仍优先于略码。显式续写声母不触发首选后置；普通补辅仍沿用原有后置和排名规则。补辅后的四字词查询保留原有分隔与 quality 修正，不把四字词辅序套到未完整编码的长补全上。
