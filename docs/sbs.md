# 21×26 声辅声混合入口

冰雪鹤道、冰雪鹤拼、冰雪鹮道共用 `SBS` 分支。`S` 是 21 个声母键，`B` 是五辅键 `aeuio`，`U` 是全部 26 个字母键；第二键在二字词中解释为第一字韵母，在三／四字词中解释为第二字首辅。此入口不以二字词空桶为前提，已有二字词和新增词语一起查询、排序和学习。

| 阶段 | 二字词解释 | 新增解释 |
| --- | --- | --- |
| `SBS` | 第一字完整双拼、第二字声母，可按空格选词 | 三字词 `S₁B₂₁S₃` |
| `SBSB` | 补完第二字韵母，形成二字全码 | 三字词 `S₁B₂₁S₃B₁₁` |
| `SBSS` | 补完第二字韵母，形成二字全码 | 四字词 `S₁B₂₁S₃S₄` |

第四键为 `B` 时继续三字词，为 `S` 时转入四字词；第五、六码只追加五辅。三字词最多六码，完整路径为 `S₁B₂₁S₃B₁₁B₂₂B₃₁`，辅序 `2123`；四字词最多六码，完整路径为 `S₁B₂₁S₃S₄B₁₁B₄₁`，辅序 `214`。数字包含第二键已输入的辅₂。同一字位重复时取该字下一辅，缺辅即停止，不能补齐或挪用后续字位；二字词继续沿用各方案的标准辅序，冰雪鹤道／冰雪鹤拼为 `12`、冰雪鹮道为 `21`。

冰雪鹤道、冰雪鹮道使用实际键道形辅；冰雪鹤拼先取词中实际读音的声调，第二字重复取辅时再取该字首笔。笔画遵守 `translator/shape_sources`，默认采用 `G` 与无标签笔顺。预编辑中的 `·` 表示第二字没有输入音码，形辅提示显示 `形₂₁₂₃`／`形₂₁₄`，调辅与首笔混用时显示 `调笔₂₁₂₃`／`调笔₂₁₄`。

| 目标 | 冰雪鹤道 | 冰雪鹤拼 | 冰雪鹮道 |
| --- | --- | --- | --- |
| 输入法 | `vuf`、`vufe`、`vufeo`、`vufeoa` | `vaf`、`vafi`、`vafiu`、`vafiuu` | `vuf`、`vufe`、`vufeo`、`vufeoa` |
| 人工智能 | `resn`、`resni`、`resnia` | `risn`、`risne`、`risnee` | `rexn`、`rexni`、`rexnia` |

三码首选用空格确认；四码及以后继续沿用飞码顶屏和补辅。`SBSU` 及其后置辅码可使用词长直选：`<` 选四字词，`>` 优先选三字词；即使相应双拼桶为空也不关闭新路径。三码不触发词长直选。学习、用户固顶、简繁转换、缓冲和首选后置沿用现有候选链；标准音码入口及其原辅序继续可用。

实现使用原生词典的省略音节代理查询，保留候选实际读音及原生用户词典。`?` 只在内部代理中表示省略音节，不进入实际输入字母表；代理候选统一经过 `snow.prepare` 修正消耗长度和质量。运行时不读取或扫描源码词库，不生成独立的词语候选表。评测编码枚举由 `scripts/lib/benchmark-schemes.ts` 的 `sbsCodes` 与实际路由同步，候选与延迟由推送后的 GitHub Actions 验证。
