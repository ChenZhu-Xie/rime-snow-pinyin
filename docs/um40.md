# 冰雪鹤道、冰雪鹤拼的 UM40 布局历史

本文记录 `ddab179` 引入 UM40 时的状态。两个生产方案现已从其父提交恢复为 RC26，当前配置与验证步骤见 [RC26 布局说明](hedao.md)；以下「当前」均指该历史提交的状态，生成命令也仅适用于该提交。

当时两个方案共用 `UM40-ac9707a932d1`（R11 页面中的「偏向 2x」），分别保留键道形辅和声调／笔画辅码。页面原始音节及码表见 [冻结来源](shenyun-um40-source.json)，完整映射及当时的配置见 [映射快照](shenyun-um40-mapping.json)。来源为用户指定的 `shuangpin-layout-benchmark/a7_CKT_R11.html`，文件 SHA-256 保存在冻结来源中。

声母 `zh→W`、`Y/YU→S`，`q→F`、`x→Y`、`s→Q`、`W→J`、`A/E/O→Y`；其他普通声母使用原键。韵母以活动配置为准，包括 `ai→T`、`ei/er→C`、`en→Q`、`ia/ong→R`、`ian/ua→W`、`iang→F`、`iao/uai→Z`、`ie→S`、`in→D`、`ing/uang→E`、`iong→V`、`iu→X`、`uan/van→M`、`ve→B`。`v` 表示 ü；五辅仍为形义序 `AEUIO`、声调序 `IEUAO`，满足 `42310` 往返不变量。

冰雪鹤道的二／三／四字词形辅序为 `12/12/24`；冰雪鹤拼的调辅序为 `12/21/13`。声声空桶按标准二字词辅序的反序，逐字取两辅至六码。字母只借用已有单字占用桶，保留汉字首选，大写、小写依次为第二、三选；共同尾键为 `n`，D/J/X 例外为 `dq/jv/xo`。两个方案改用新的 UM40 棱镜及独立固定编码用户词典名称，避免旧物理短码混入；以拼音保存的公共词频继续共用。

## 迁移审计

| 口径 | 旧 RC26 | UM40 |
| --- | ---: | ---: |
| Common399 唯一码 | 399 | 399 |
| Common399 重码桶／受影响音节 | 0／0 | 0／0 |
| Common399 空码 | 147 | 147 |
| 扩展 416 音节唯一码 | 413 | 411 |
| 扩展域重码桶／受影响音节 | 3／6 | 5／10 |
| 运行时 AU 空桶 | 142 | 144 |
| 运行时 AA／AB 空桶 | 129／13 | 134／10 |

Common399 和扩展域按映射快照计数；运行时按五部系统词典、排除大字集兜底读音的规则计数，不能混用。UM40 的 `qz` 是声声空桶，`zq` 是 `zen` 单字桶；新回归同时覆盖两个边界。当前两份固顶表各有 21 个一简、376 个二码单字、117 个二简词和 26 个字母入口。旧 RC26 的映射与键位图以历史文件名保留，不再表示活动布局。
