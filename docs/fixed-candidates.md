# 单字固顶选字原则

## 本次范围与当前状态

本次为冰雪鹤道（`snow_hedao`，无调 21×26）和冰雪鹮道（`snow_huandao`，带调 21×26）补齐「两码主码＋第一形辅」的三级单字固顶。冰雪鹮道的声调已包含在第二码中，第三码仍取本字第一形辅。冰雪鹤拼及其他拼系列暂时沿用现有固顶规则；不新增 630，也不改变声韵映射、形辅映射或词语路由。

两套方案已由 `scripts/align-fixed-with-sipin.ts` 分别生成 1,648 和 2,022 个三级单字固顶，保留原有一／二码条目。固顶表、方案文档和候选回归随生成器同步维护，不能仅手工补写生成产物。

## 常用度的口径与证据

本次希望优化的「常用」是单字独立作为词使用的频率，即一字词频；一个字在二、三、四字及更长词语中的出现次数不应直接算入这项频率。词典中存在单字条目，或该条目具有较高权重，本身不能证明它的权重采用了一字词频口径。

当前阶段不追查、重算或采集真正的一字词频，也不把取得这种数据作为三级固顶的前置条件。现有单字读音权重可以作为兜底排序信号，但其是否排除了多字词贡献尚未确认，不能将据此选出的结果称为「按独立出现频率优化」。`scripts/experiments/frequency/derive-character-frequency.ts` 是未接入生产固顶流程的实验工具，本次不运行它来建立新的频率依据。

冰雪四拼的单字固顶作为重要的选字偏好：参考它选择了哪些字、对应读音及短码层级，按目标方案的实际音码和形辅重新分桶。四拼的二／三级固顶也受自身码位冲突与记忆安排影响，不是严格的一字词频排名；不得将其当作唯一候选白名单，或直接复制四拼的物理编码。四拼的三级音码固顶与道系列的「主码＋一形辅」不是同一编码层级。

现有流程用四拼单字固顶对齐一／二级单字位；21×21 形辅方案的三级单字池另行结合外部方案短码证据、已有固顶偏好与词典权重选字。两套 21×26 三级固顶独立提取四拼单字固顶的「字＋读音」及最短层级，显式参与三级选字，不能仅依赖短码层的对齐。

## 当前生成策略

候选取自 `scripts/data/tygf-pinyin.tsv` 中的通用规范汉字读音，并按各方案的实际代数和第一形辅生成三码。五辅转换通过「折、横、撇、竖、点」语义映射完成，保持 `42310` 往返合同。先排除全部一／二码固定单字（包括字母入口的汉字首选），再按可选字数量由少至多分配码位，平局按物理码排序；每字最多占一个三级位。

桶内优先选择有四拼单字固顶依据的读音，先比较四拼最短固顶层级，再按当前读音权重降序择优；没有四拼固顶依据的字仍可按读音权重补位。相同层级、相同权重时按字和读音稳定排序。不按同字其他读音汇总权重，也不以完整形辅码长度加分。

## 选字与码位约束

- 候选必须由目标方案的当前读音生成两码主码，再追加本字第一形辅；按实际物理码分桶。多音字的权重属于「字＋当前读音」，不得借用同字另一读音的高权重。
- 已占用一／二级单字固顶的字不再占三级位，三级单字之间也不重复分配同一个字。保持既有短码、二简词和字母候选合同，不借用词语路由填充单字固顶。
- 在合法且去重后的候选中，优先结合四拼单字固顶等短码使用证据判断哪些字值得固定，现有单字读音权重用于补充和兜底。没有合适候选的槽位允许留空，不以填满理论空间为目标。
- 各方案的单字和词语固顶均不以完整码长度、实际输入按键数或全码候选名次作为加分、同分优先或让位依据；同等条件下也不优先照顾长码或需要额外选重的字词。不能因某字词全码已是首选，就剥夺它参与固顶选优的资格。
- 某槽位的自然首选若已合适，可以继续固定该字以保持稳定；不能仅为更换首选而换入更生僻的字。固顶不必都产生额外节键收益，也不追求覆盖所有更长辅码层。

## 实现与验证要求

生成检查应覆盖编码合法性、短码与三级单字去重、四拼偏好的语义重映射、多音字读音权重隔离，以及重新生成结果的稳定性。不得套用其他布局的物理输入串或候选次序。

一码单字统一按四拼的字与读音重映射，不再按全码选重深度将 `p` 特判为「配／平」。七套双拼的 `p` 恢复为「跑」；冰雪鹮道将「跑／我」映射到同一声母，按原有四拼重映射顺序取「我」。630 选词保留日常语用、短码证据、既有固顶及词典权重，不再计算全码选重困难加分或全码首选让位名单。四拼已有短码层级仍作为明确的选字依据；同字去重和尾字键等可直接构造词的规则分别维护已有入口与功能分工，不据此奖励长码字词。

真实候选回归应检查三级固顶的 `cand[1]`，并覆盖继续补辅时的候选行为，避免用候选仍然存在代替首选正确。涉及实际输入成本的结论应由候选验证支持，静态估算必须标明口径。先完成本地静态、生成和语料检查，再推送，由 GitHub Actions 在 librime 1.13.1 与 1.17 上验证；本机不运行 Mira。

## 八套双拼方案的英数与生僻字合同

冰雪兰道、兰拼、键道、三拼、莲道、鹤道、鹤拼、鹮道均须保有 26 个大小写字母入口及 0～10 的数字固顶别名。21×21 字母由各自棱镜解释，21×26 字母由占用桶配置和 `shenyun` 翻译器提供。21×26 重生成时移除旧布局遗留的字母后缀，再按当前配置恢复唯一入口，维持汉字首选、大写第 2、小写第 3；不得让旧入口随着汉字行继续残留。

三套 21×26 数字别名统一由 `align-fixed-with-sipin.ts` 生成，机器可读结果见 [`config/shenyun-21x26-number-codes.json`](../config/shenyun-21x26-number-codes.json)。先寻找对应汉字数字三码以内已有的最短固顶码，否则取本方案主码加该字第一形辅／调辅。数字追加在该码原有候选之后，保留该码已有汉字首选和字母位次；不借用声声空桶或 `ABA`、`AAB`、`AAAB` 词语空间。冰雪鹤拼因此允许数字别名使用三码，但不扩展普通三级单字固顶。

本轮补齐冰雪鹮道遗漏的「3」，并解除旧数字别名对汉字选字的反向影响：`lz/pu/qz/rf/sk/wd` 的汉字首选分别按当前读音恢复为「一／五／七／二／四／六」，替代旧表的「唷／排／期／贰／赤／露」。这是重新按汉字数字语义生成的结果；数字附加步骤本身不再改动汉字首选。

冰雪鹮道的「3」复用 `sm`，该码也是 S 的字母入口，固定顺序为「三、S、s、3」。数字不能挤占大写第 2、小写第 3 的位置；其余入口与完整数字码表以生成配置为准。

21×26 的单键声声空桶提示插在整个一级固顶前缀之后；例如冰雪鹤道、鹤拼的 `q` 先显示「三、3」，随后才是空桶提示和其他自然单字。只固定一个汉字的其他单键沿用原提示顺序。

生僻字补位仍遵循各方案自己的单字层级、候选优先级和去重规则。规范字集中的生僻字可以补位，繁体原字与扩展区字保留词典读音和合法输入路径；不要求上游选中的每个字在本地也占一个短码。新增两套道系三级单字的候选池继续限定为通用规范汉字，常用度口径沿用本文的一字词频原则，暂不另行采集字频。

`fixed-entry-contracts.test.ts` 对八套实际生效的全表逐条检查大小写字母入口、数字读音、单字词典读音和本地辅码，覆盖生僻字及繁体原字，而非只检查几条示例。经典方案保留的兼容拼写也须由现有代数接受；历史重复码按运行时 `snow.read_dictionary` 的最后一行生效规则审计，不能将被覆盖的早期行算作有效固顶。

简繁显示另行验证：默认简体模式后置繁体原字，不删除生僻或扩展区候选；繁体模式保留输入顺序，交给 `simplifier` 转换。共享 Lua 单测覆盖后置、透传及缺少 OpenCC 的行为；八套真实候选 spec 各取一个生僻固顶检查 `cand[1]` 和真实固顶标记，并在独立繁体部署检查「来→來」。完整码合法性、短码首选与简繁转换分别承担各自的合同。

## 单字右括号与词语固顶分工

全部十一个冰雪方案共用单字定字处理器：单字候选按 `[` 重复该字，按 `]` 上屏该字并追加「是」；多字候选仍分别取首字、末字，无候选保持原行为。

二字词以「是」结尾时不再占用 630、二简词或其他固定词条，普通词典条目和自然输入路径保留。八套双拼由生成器按各自码位补选；四拼、清韵、一拼的手工固顶表移除这些词，保留同码其他候选。原先因单字 `]` 追加「得」而排除的二字词不再受该规则限制，重新参与正常选优。这里只规定功能分工，不保证所有「单字＋]」都比原固定词更短。

评测的单字结构输出枚举同步增加 `字是` → `单字编码＋]`，只限单字，不能为多字候选添加追加「是」的路径。旧报告与缓存对应原规则，不能作为本轮固定词迁移后的成绩。

## 声声短路径的尾字排除

八套双拼的声声二字词路径，无辅及带形辅／调辅均排除以「的、了、是」结尾的二字词。21×21 在声声查询和辅码过滤处执行，21×26 在 AA 路由进入候选合流前执行；三字以上、普通完整音码和其他词语路由不受此规则影响。「×得」不在排除范围内。

本规则按输出字面判断，包含「目的」「除了」等不同读音的二字词，不依读音豁免；这些词仍可通过完整音码输入。声声空桶提示同步使用过滤后的候选池，避免提示无法选出的词。
