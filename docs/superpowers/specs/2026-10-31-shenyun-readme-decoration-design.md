# 神韵文档装饰与热力图设计

## 意图

让 README 与比较报告在重新生成后仍稳定保留两类比较标记、原地链接和一致的热力图版式，不再依赖生成后的手工修补。

## 规则

- `**…** ★` 只比较无飞键道(U357) 21×21 双拼与星空键道 S005；并列较优时两格都标。
- `🥇` 比较四个方案；并列全局最优时所有并列格都标。
- 比较方向由指标元数据给出：越低、越高、越接近 50%，以及飞键三元组总量；复合碰撞桶没有单一方向，不标胜负。
- README 的简体中文、英文、繁体中文三张表及 `reports/shenyun-comparison.md` 的可比较表均由同一装饰函数生成。
- 方案名、指标解释、报告、JSON、SVG 与生成脚本等已有可靠目标的文本使用原地 Markdown 链接；不为普通叙述强加重复链接或制造嵌套链接。
- 两张热力图都直接取自 benchmark HTML。神韵(Overall-17) 21×26 双拼沿用无飞键道(U357) 21×21 双拼的裁剪范围和背景，标题统一为简短的“纯双拼键频图（含标点）”。
- 两套方案的声韵图标题统一为“声韵辅-键 映射”，英文和繁体使用对应译文。

## 方案选择

采用生成器驱动方案：把比较、格式与链接规则写入脚本并加 `--check` 回归验证。放弃只改 Markdown 的方案，因为再次生成会丢失标记。

## 非目标

- 不改变任何方案映射、候选排序或 CKT 数值。
- 不用图像生成或手工重绘替代 benchmark HTML 的 SVG。
- 不给没有单一优劣方向的复合碰撞桶强行颁奖。
