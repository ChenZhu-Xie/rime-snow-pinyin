# 单字首选生产问题核对

所有真实候选均由 GitHub Actions 在独立部署、空用户词典中采集。逐个输入串使用新会话，不把此前上屏学习带到后字；同一输入串内部仍保留生产方案的首选后置。不能以最终全码的候选位次代替逐键最短首选。

## 短部件与笔画来源

星空键道码表本次读取的完整提交为 `7394f8e2c4770bde0a64bd5f6a49e52a278d291a`。其 `rime/keytao.single.dict.yaml` 中「几、乙、口、曰」分别具有 `jkuaa、ykaa、kdoo、yhoii`。规则是单字现有形辅不足四码时重复一次末辅，并非补足四辅。实现集中在 `lua/snow/shape_completion.lua`，词组取辅不变，离线生成器同步处理。

「尖、尘」已有笔顺分别为 `234134、234121`，但原来源标签不含默认启用的 `G`，因此无法筛选。依据[《通用规范汉字笔顺规范》](https://hudong.moe.gov.cn/jyb_sjzl/ziliao/A19/202103/W020210318300204215237.pdf)第 0414、0415 字，生成器合并大陆来源，保留其他地区标签；修正源为 `scripts/data/stroke-source-corrections.tsv`，不手改生成词典。
