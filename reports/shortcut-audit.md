## 三、缓冲入口

| 方案 | 当前行为 | 上游行为 |
| --- | --- | --- |
| 冰雪四拼、冰雪三拼、冰雪键道 | `Ctrl+B` 直接切换；`o` 候选也可开启或关闭 | `Ctrl+J` 直接切换；`o` 候选只能开启，不能关闭 |
| 冰雪一拼 | `Ctrl+B` 或 `jio` 并击可开启和关闭 | `Ctrl+J` 只能开启；没有 `o` 入口 |
| 冰雪清韵 | `Ctrl+B` 可开启和关闭；没有 `o` 入口 | `Ctrl+J` 可开启和关闭；没有 `o` 入口 |
| 两套冰雪神韵 | `Ctrl+B` 或 `o` 候选均可开启和关闭 | 上游无对应方案 |

因此，上游 `o` 不是 toggle：其翻译器固定显示“开启缓冲”，选中后固定写入 `buffered = true`。当前 fork 才把 `o` 改成根据现状开启或关闭。

## 四、手动加词与固定候选

七套方案现在都加载 `snow.user_dict`、启用方案用户词典，并在方案状态中显示「结束／加词中」。

手动加词是两段式操作：

1. 输入以后用于查询新词的目标编码，保持候选存在。
2. 按 `Ctrl+.`，候选清空，方案状态变为「加词中」。
3. 正常输入并上屏新词的全部文字，最后一段也必须先上屏。
4. 再按 `Ctrl+.` 保存；按 `Escape` 则取消。
5. 重新输入目标编码验证新词。

| 按键 | 功能 | 相对上游 |
| --- | --- | --- |
| `Ctrl+.` | 开始/完成手动加词 | 上游使用 `Ctrl+'`；功能相同，本地补齐到冰雪一拼和两套冰雪神韵，并统一加入可见状态 |
| `Ctrl+/` | 固定/取消固定当前候选 | 上游使用 `Ctrl+;`；功能相同 |
| `Ctrl+[` / `Ctrl+]` | 将已固定候选前移/后移一位 | 相同；分支落空时也消费按键，不再穿透成清空 |
| `Ctrl+\` | 重置当前编码下的全部方案固定候选 | 相同 |

用 `Ctrl+.` 加入且不在静态词典中的词，可选中后按 `Ctrl+/` 禁用。普通 Rime 自动学习词则使用 `Ctrl+Delete` 删除或取消调频；两者不是同一套数据库流程。

## 六、冰雪四拼结构略码

结构略码只在候选存在、候选少于四字且按键没有继续参与正常编码时触发。以当前候选 `AB`、首字 `A`、末字 `B` 表示：

| 按键 | 结果 | 相对上游 |
| --- | --- | --- |
| `[` | 单字重复一次 | 保留 |
| `D / L / B / F / R / U` | `AB + 的/了/不/一/啊/呀 + AB` | 保留 |
| `K` | `AB了一AB` | 本地新增 |
| `J / P / N` | `A + 了/不/里 + AB` | 本地新增 |
| `G` | 单字生成 `A个`，多字生成 `A个B` | 本地新增 |
| `E / T` | `A+AB` / `B+AB` | `E` 保留，`T` 本地新增 |
| `Y / I` | `AB+A` / `AB+B` | `I` 保留，`Y` 本地新增 |
| `A` | `ABAB` | 保留 |
| `O` | 二字词生成 `AABB` | 保留 |
| `W` | `AB着AB着` | 保留 |
| `Q` | `AB来AB去` | 保留 |

两套冰雪神韵也加载同一结构处理器，但编码键域不同；大写字母只有在不构成正常编码时才作为结构键。

## 七、按功能比较的结论

按照“相同功能即使换键也不重复列举”的口径：

### 上游有、当前没有

- 左 `Shift` 行内临时英文：上游 `inline_ascii` 会临时进入英文并在回车后返回中文；本机改为 `commit_text`，没有等价的一次性临时英文入口。

### 当前有、上游没有

- 编码物理循环移动、逻辑字位/音节循环，以及冰雪三拼、冰雪键道和冰雪神韵的数字字位直达。
- `Ctrl+P` 一步执行“开头后右移两码”。
- `Ctrl+H/L` 一次跨两个候选。
- 冰雪一拼可以用快捷键直接关闭缓冲；上游冰雪一拼只能开启。
- 冰雪四拼新增的 `K/J/P/N/G/T/Y` 结构略码。
- 跨方案、可翻页、去重并过滤纯标点的扩展历史面板。
- 两套冰雪神韵及其整套快捷键适配。

### 功能相同、仅按键不同

以下不算功能增删：翻页、候选上下移动、移到开头、删除输入码、清空输入、缓冲切换、Unicode 开关、固定候选和手动加词。当前只是按本地布局重新分配了按键。

上游 `Ctrl+G`、`Ctrl+[` 清空以及 `Alt+V` 翻页虽然被移除，但 `Escape`、`Page_Up`、`Ctrl+M` 等入口仍提供相同功能；上游 `Ctrl+K → Shift+Delete` 的删词别名被移除后，`Ctrl+Delete` 仍保留普通用户词删除功能。
