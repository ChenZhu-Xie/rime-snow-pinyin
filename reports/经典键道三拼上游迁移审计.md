# 经典冰雪键道／冰雪三拼上游迁移审计

## 审计边界

历史基线为 `3658e22a151cfaa703a68e3a47a16101efd88e42`，下一提交 `b8fd127da9ecb14d07da1ce9a680ca92d91837f0` 开始替换双拼布局；本轮对照的上游主线为 `99c1d6010ff7252175f2b373f05ff30e9541f3c3`。`scripts/data/legacy-schemes/3658e22/` 保持原样并由 SHA-256 回归锁定；发布用的 `snow_jiandao_classic`、`snow_sanpin_classic` 是适配层，不要求复刻历史缺陷。

经典发布方案只保留迁移前的声韵布局与三拼主码。追加辅码采用本仓库 CKT v5.1 的稳健第一：冰雪键道与冰雪健道共用 `12/231/24`，冰雪三拼与冰雪弎拼共用 `12/213/23`。因此 benchmark 比较的是“经典音码＋现行辅序＋现行功能”，历史旧辅序只留在原样快照中作证据。

## 对照结论

| 上游后续能力 | 经典发布版处理 | 结果 |
| --- | --- | --- |
| processors、segmentors、translators、filters 的统一顺序 | 直接复用当前 schema 组件顺序与当前 `lua/snow/` 实现 | 两组经典方案与对应现行方案的组件集合对齐；键道反查节点仅因经典代数保留独立名称 |
| 输入统计、缓冲、用户固顶、手动加词、历史、Unicode、计算器、日期与数字 | 复用当前 Lua；经典键道复用 `snow_jiandao` 用户库，经典三拼复用 `snow_sanpin` 用户库 | 功能与用户学习不形成孤岛 |
| 词频后置、固定候选流式输出、代理码质量修正、简拼完整码查询优化 | 复用当前 `postpone.lua`、`fix.lua`、`table_like.lua`；经典键道也改用 Lua 简拼翻译器 | 不保留 3658e22 的旧性能路径 |
| 三字及以上简拼的大写补韵 | 迁入当前 `append_raw`／四声母后转小写规则，并按经典双拼棱镜派生大写韵键 | 冰雪键道、冰雪三拼与冰雪健道、冰雪弎拼功能对齐；前三字可写 `A[U]A[U]A[U]` |
| 部件拼音、笔画来源筛选与部件／拼音反查 | 引入当前依赖、翻译器、过滤器及形码数据；只把经典拼写代数用于反查格式 | 功能不低于上游当前键道／三拼 |
| `;/` 强制顶出并追加“的／了”、`_23890` 选重布局、当前快捷键 | 按当前方案迁移，删除历史 `Control+j`／`Control+l` 私有绑定 | 与现行方案交互一致 |
| AA 空桶二字词与 AAB 单辅码 | 按经典双拼实际单字占桶重新计算；经典键道走空桶二字翻译器，经典三拼沿用两声母代理查询；AAB 分别取第一字形辅、第二字调辅 | 经典音码域实测为 382 个已占二码、59 个空 AA；fixed 表覆盖全部 59 个空位 |
| 630 固顶 | 保留经典音码重新选词并补齐空槽，不照抄 U357 码位 | 经典键道 630/630 且词项不重复；经典三拼 629 个有效码位，高于上游现行表的 611 个 |
| 生僻单字补空 | 对历史表的重复字按同码候选重新选取，优先使用尚未固顶的同码字 | 经典键道单字表有 2,061 个码位、至少 2,046 个不同汉字，不少于现行键道 2,005 个；经典三拼 398 个码位对应 398 个不同汉字，不少于现行三拼 387 个 |
| 拉丁字母与临时数字 | 按经典主码重编码；三拼轻声仍用经典键 `a`，不能照抄现行 U357 的 `o` | 三拼补齐 26 个字母、7 个临时数字，并给“一二三四”保留阿拉伯数字别名；键道在空 AA 二简行合并字母候选 |
| 新增词典异拼与扩展音节 | 发布适配层处理 `r5`、`lvan`，明确排除旧布局无法编码的扩展音节 | 九方案 1,709 种词典读音结构检查通过 |

## 有意保留的差异

- 不迁移 U357／Overall-17 的声韵映射、飞键消除、音节碰撞及其物理韵键映射；这些属于冰雪健道、冰雪弎拼、冰雪简道、冰雪散拼的布局合同。大写补韵这项功能本身已经迁移，但大写字母仍按经典双拼棱镜解释。
- 不照抄现行 fixed 文件的物理码。630、字母、数字、生僻字和空桶词均先还原其功能意图，再按经典音码重新编码并检查候选存在性。
- 经典三拼的完整单字三拼仍使用历史声调键 `viuoa`；“共用辅序”指二／三／四字词追加辅码的字位顺序采用 `12/213/23`，不把经典三拼主码改写成冰雪弎拼。
- 经典 schema 使用独立 `schema_id`、prism 和 fixed 文件，以便与现行方案同时安装；自定义用户固顶数据库则显式复用对应现行方案。

## 回归门禁

`scripts/fixed-corpus/test/legacy-benchmark-schemes.test.ts` 锁定历史快照哈希、经典主码、CKT v5.1 辅序、AA/AAB 路由、630 覆盖、单字去重下限、字母／数字表和共享用户库。`scripts/check-pinyin-dict.ts` 同时展开九个发布方案的实际拼写代数，避免经典适配层在后续上游合并中再次落后。
